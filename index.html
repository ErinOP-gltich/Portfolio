Try it live

Four small tools running right here in your browser, straight from my networking, security and blockchain work. No server, no libraries.

Subnet calculator

Enter any IPv4 address and prefix length. Change the prefix to watch the network and host bits move.

Mini blockchain

Each block stores the SHA-256 hash of the one before it. Edit any block’s data and every block after it breaks. Mine a block to find a nonce whose hash starts with the required zeros.

Firewall ACL tester

Write Cisco-style extended access-list rules, then send a test packet through them. Rules are checked top to bottom, the first match wins, and anything that matches nothing hits the invisible “deny any” at the end, just like on a real router.

Supports permit/deny; ip, tcp, udp, icmp; any, host or wildcard masks; eq, neq, lt, gt, range. Named ports work too: www, https, ssh, telnet, ftp, domain, smtp, ntp, snmp, rdp. Lines starting with “remark” or “!” are comments.

    Password strength checker

    Type a password to see its estimated entropy, how long it would take to crack in three attack scenarios, and which patterns make it weaker than it looks. It runs entirely in your browser, and nothing is stored or sent.

    Good habit: never type your real passwords into a website you don’t trust, including this one.
