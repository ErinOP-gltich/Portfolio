03 — Toolbox

Four tools. All of them actually run.

Written from scratch, no libraries, nothing sent to a server. Use them.

Subnet calculator

Any IPv4 address and prefix. Change the prefix and watch the network and host bits move.

Mini blockchain

Each block stores the SHA-256 hash of the one before it, on a hash function written by hand. Edit a block and everything after it breaks. Mine it to find a nonce whose hash starts with the required zeros.

Firewall ACL tester

Write Cisco-style extended access-list rules, then send a test packet through them. Rules are checked top to bottom, first match wins, and anything unmatched hits the invisible deny at the end, just like on a real router.

Supports permit/deny; ip, tcp, udp, icmp; any, host or wildcard masks; eq, neq, lt, gt, range. Named ports work too: www, https, ssh, telnet, ftp, domain, smtp, ntp, snmp, rdp. Lines starting with “remark” or “!” are comments.

    Password strength checker

    Estimated entropy, crack times in three attack scenarios, and the patterns that make a password weaker than it looks. Everything runs in your browser, and nothing is stored or sent.

    Never type a real password into a site you don’t trust, including this one.
